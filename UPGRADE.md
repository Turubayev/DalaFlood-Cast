# Доработка и доказательства готовности

Дата: 2026-10-09.

## Реализовано

Убраны bfill/интерполяция с будущими наблюдениями и подмена пропущенных целей. Неполные окна исключаются. HBV и кривая Q→H обучаются только до calib-from; конформная калибровка отделена от теста. Интервал не сужается отрицательной поправкой; кривая расходов монотонная. Добавлен архив выпущенных метеопрогнозов. Старые контрольные точки требуют явного --allow-legacy-research-model для воспроизведения.

## Аналог и применённый подход

[NeuralHydrology](https://github.com/neuralhydrology/neuralhydrology)

Разделение периодов обучения, калибровки и оценки, сохранение источника цели и параметров эксперимента. NeuralHydrology не установлен; существующие HBV/LSTM сохранены.

## Запуск и проверка

```bash
python -m pytest -q
python scripts/train_level.py --gauge esil_petropavl --obs your_gauge.csv --weather-archive issued_daily.csv --calib-from 2018-01-01 --test-from 2021-01-01
```

Регрессионные тесты: `python -m pytest -q`. Локальная среда проверки: Windows, Python 3.12. CI проверяет отдельную чистую среду.

## Что требуется для оценки 10/10

Нужны реальные наблюдения гидропостов и переобучение текущих весов. Формат issued_daily: issue_time,issued_at,valid_time,temperature_2m_mean,precipitation_sum, полное покрытие суток 1–3 на каждый выпуск. Старые оценки на GloFAS не доказывают точности на измеренных расходах. Карту HAND/S1 проверять на нескольких паводках с вычитанием постоянной воды. Онлайн snow/soil forcing пока требует отдельной проверки полноты; прогноз не заменяет предупреждения служб.

Инженерные тесты подтверждают поведение кода; они не измеряют клиническую, гидрологическую или коммерческую точность. Метрики на синтетике нельзя переносить на реальные данные. Оценка 10/10 сейчас не заявляется.
